# Campus Canteen Expense Tracker

A zero-dependency Node.js workshop project.

See [AGENTS.md](AGENTS.md) for project commands and repository guidance.

Try these workflow prompts in order (from `.agents/prompts/`):
- `/1-visualize` — understand the app.
- `/2-add-feature` — add workshop features.
- `/3-test-and-verify` — test and verify them.
- `/4-build-and-deploy` — build and deploy the app.
- `/5-debug-production` — debug build, deploy, and runtime errors.
- `/6-plan-persistence` — plan persistent storage for items.

## Checkout the starting state

To check out the version where the expense requirements are not implemented:

```powershell
git switch --detach requirements-not-implemented
```
